TIANAO furniture image renaming notes
The files are prefixed with the closest matching product/model label visible in the supplied PDF.
Original filenames are retained after the double underscore so each image can be traced back.
Some catalog pages contain multiple products or tiny/unclear model text; labels such as DINING-01, BED-01, and CABINET-01 are descriptive rather than model numbers. Please verify model-code prefixes against the original artwork before using them for production.
